# Resources

Generated per app by Sprint 04, hand-written here so the generator has a target.

| File                                        | Rewritten from                           |
| ------------------------------------------- | ---------------------------------------- |
| `Info.plist`                                | Generated by XcodeGen from `project.yml` |
| `Assets.xcassets/SplashBackground.colorset` | `config.branding.splash.backgroundColor` |
| `Assets.xcassets/AppIcon.appiconset`        | `config.branding.icon`                   |
| `appconfig.json`                            | The customer's configuration             |
| `offline.html`                              | Shared with the Android shell            |

⚠️ Permission strings in `Info.plist` are removed entirely when the config does
not request the capability. An unjustified permission is a common rejection
reason, and a _missing_ one crashes the app the moment a web form asks.
